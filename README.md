# 研究者紹介ページ

素の HTML / CSS / JavaScript だけで動く 1 ページのプロフィールサイト。
ビルド不要で、`index.html` をブラウザで直接開けば確認できる。

```
index.html          本文（日本語と英語を両方書いてある）
assets/style.css    見た目
assets/main.js      言語トグルと年号の埋め込み
```

## 中身の書き換え方

日本語と英語は同じ HTML の中に並べて置いてあり、CSS が `<html lang="...">` を見て
片方を隠している。書き換えるときは 2 つセットで直す。

```html
<span class="ja">日本語の文</span><span class="en">English text</span>
```

差し替えが必要な箇所は `class="ph"`（placeholder）が付いていて、画面上では
点線の下線とグレーの文字で表示される。埋め終わったら `class="ph"` を消していく。
全部埋まったら `assets/style.css` の `.ph { ... }` のルールごと削除してよい。

書き換えるときのチェックリスト:

- [ ] `<title>` と `<meta name="description">`（`index.html` の先頭）
- [ ] 名前（ヘッダー、ヒーロー、フッターの 3 か所）
- [ ] 所属・専攻・研究室
- [ ] 冒頭の一文とキーワード 3 つ
- [ ] 自己紹介 2 段落
- [ ] 研究テーマ 3 枚のカード（数は増減してよい）
- [ ] レジュメ（学歴 / 職歴 / 論文 / 学会発表 / 受賞 / スキル）
- [ ] 連絡先のメールアドレス

現時点では外部リンクを一切貼っていない。メールアドレスもリンクではなく
ただのテキストなので、`mailto:` にしたくなったら手動で `<a>` を足す。

## 公開する

GitHub Pages なら、リポジトリの Settings → Pages で Source を
"Deploy from a branch" にして公開したいブランチと `/ (root)` を選ぶだけ。

## 補足

- 配色はライトモードとダークモードの両方に対応（OS の設定に追従する）。
- 印刷 / PDF 保存用のスタイルも入れてあるので、ブラウザの印刷から
  そのまま紙の CV に近い形で出力できる。
- 外部フォントも CDN も使っていないので、オフラインでも表示は変わらない。
